# 문구 표 — 지금 글 → 새 글 → 이유

새 화면(`web/`)의 사용자 문구는 모두 `web/src/copy/ko.ts` 한 파일에 있고, 이 표가 그 기준이다. 규칙은
`docs/VOICE_AND_TONE.md`(해요체, 한 문장에 한 뜻, 내부 말 금지, 단추는 `~기` 동사, 오류는 "무슨 일 + 할 일").
화면 설계는 `docs/UI_SPEC.md`.

- **1절**: 이 줄(RX0)이 새 화면으로 만든 곳(앱 틀·로그인·가입·홈·프로토콜 목록)의 문구 — 지금 화면의 모든 문구를 새 글로 바꿨다.
- **2절**: 아직 옮기지 않은 화면의 문구 중 대표가 지적했거나 내부 말인 것 — 다음 줄이 옮길 때 쓸 새 글.
- **3절**: 설정의 용어.
- **4절**: **서버가 보내는 문구**(오류 코드의 뜻, 카드 질문, 음성 문장) — 이 줄에서 바꾸지 않고 목록만 남긴다.
- 내부 말(검토본·리비전·사유 코드·개발 상세 정보·LAB COPILOT·카탈로그·세션 등)은 사용자 화면에서 뺀다.
  `이 프로토콜로 시작`(`AGENTS.md` 규칙 5)과 원문 인용·숫자·단위는 바꾸지 않는다.
